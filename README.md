## 🧑‍💻 About The Project

**Portfolio 2026** is a premium, immersive and interactive personal portfolio website designed to showcase my journey as a **Full Stack Developer and AI/ML Enthusiast**.

Instead of creating a traditional portfolio, this project focuses on delivering an engaging digital experience using:

* 🌌 **Three.js-powered 3D graphics**
* 🎬 **GSAP animations**
* 🧊 **Glassmorphism UI**
* ✨ **Interactive WebGL effects**
* 📊 **Dynamic GitHub statistics**
* 📱 **Fully responsive design**
* ⚡ **Performance-focused JavaScript**

> The goal is simple: **turn a portfolio into an experience.**

# ⚡ Getting Started

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Saksham9934/Portfolio-2026.git
```

## 2️⃣ Open Project

```bash
cd Portfolio-2026
```

## 3️⃣ Run Locally

You can directly open:

```text
index.html
```

Or use a local development server:

```bash
npx serve .
```

Then open the local URL shown in your terminal.

---

# 🌍 Deployment

## ▲ Vercel

Install Vercel CLI:

```bash
npm install -g vercel
```

Deploy:

```bash
vercel
```

For production:

```bash
vercel --prod
```

---

## 🐙 GitHub Pages

1. Push the repository to GitHub.
2. Open:

```text
Settings → Pages
```

3. Select:

```text
Deploy from a branch
```

4. Choose:

```text
Branch: main
Folder: /root
```

5. Click **Save**.

Your portfolio will then be available through your GitHub Pages URL.
